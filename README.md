# Complete-graph incidence configurations: data and exact certificates

This repository contains ten complete-graph incidence-family configurations
attaining the cell bound, an exact unsigned recursive-line checker, ten
finite verification certificates and an independent proof verifier.
All ten cases have been actually verified, with zero uncertified class pairs.

Three CSV grids transcribe the full tables in the supplied paper. Seven are
independently generated replacement witnesses. Their provenance and rule
counts are documented explicitly; they are not claimed recovered originals.

## Quick start

Run from this repository root, using Python 3.12 and NumPy:

```bash
python -m pip install -r ancillary/requirements.txt
python ancillary/validate_all.py
python ancillary/test_checker.py
```

Expected results: `ALL TEN VERIFIED` and 9 tests passing.
The checker does not assume that equal printed labels are already identified.
It implements all five unsigned rules, including the prescribed-value hole
rule, and checks the fixed point and all recursive-line terminal conditions.

## Contents

- `ancillary/`: ten CSV grids, checker, independent verifier, reference
  implementation, tests, generators, requirements, summary and SHA-256 manifest.
- `logs/`: ten finite NPZ proofs, computed outputs, search records and
  independent verification results. Clearly named exploratory and incomplete
  historical logs are separate from the successful final evidence.
- `report/`: six-page English [technical report](report/technical_report.pdf)
  and its [LaTeX source](report/technical_report.tex).
- `references/`: replacement reference [21] as a LaTeX entry and a BibTeX entry.

The [complete replay index](ancillary/README.md) explains CSV conventions,
per-file commands, expected outputs, proof format and actual checksums.
The seven searched configurations were regenerated byte for byte from the
recorded seed and parameters; the three printed grids were re-extracted
and likewise checked byte for byte.

## Citation and upload

See [CITATION.md](CITATION.md) and the
[Chinese upload guide](UPLOAD_GUIDE_zh.md). Before using reference [21] in a
paper, replace the explicitly marked username with the actual repository owner.
The package does not assert that a repository or public release already exists.
Keep the bibliography key `sheets` when replacing the old reference.

After editing citation or documentation files, refresh their checksums:

```bash
python ancillary/update_checksums.py
```

## Scope

These certificates concern exactly the ten incidence dimensions shown above.
They do not certify the separate seven-column companion cases 9<=m<=16,
recover the seven unavailable original larger data sheets, or prove the
bounded-gap conjecture for all dimensions. The seven replacement witnesses
require corresponding updates to the manuscript's construction-provenance
and replay tables. Their finite proof files are included directly in the
repository tree so the entire verification can be replayed after download.
